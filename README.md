# Gloomhollow

A slow, Souls-like pixel dungeon crawler for the browser. Five floors down to the Wyrm, then loop.

**Play:** https://sickssens3.github.io/play-gloomhollow/

Works on desktop (WASD, mouse, right click to charge a heavy) and on phones (touch pad, hold the aim stick at its rim to charge). It installs as an app from the browser menu and runs offline once loaded.

Made by SicksSens3.
